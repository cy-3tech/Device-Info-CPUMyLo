# Device-Info-CPUMyLo
CPUMyLo is a cyberpunk-themed PWA combining real-time hardware telemetry, advanced Web Crypto tools (AES/RSA), and device connectivity (Serial/BLE). Features live CPU/core monitoring, a mining reference hub with profitability calc, and Mylo AI+ for context-aware tech support. A secure, mobile-first diagnostic suite running entirely in-browser.
